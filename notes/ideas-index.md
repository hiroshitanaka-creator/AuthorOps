# Ideas Index

> **目的**: AuthorOpsで思いついたアイデア・断片・参考文献・「後で考えること」を逃さないための受け皿。
> ここに書いておけば、コンテキストが薄れても後から拾い上げやすい。

## 使い方

1. 新しいアイデアが浮かんだら、このファイルの対応セクションに追加する
2. 重要度が高いものは、別途で **Issue** を作って移行する
3. 期間を空けて見直したときに「これは使えそう」と思ったら、Issue化する
